MODEL PLAYGROUND

Run my models in your browser.

Run three checkpoints of the MedSparse model or the separate Tiny GPT model in your browser. The MedSparse checkpoints cover pretraining, medical fine-tuning, and MIRIAD medical Q&A fine-tuning. Generation runs locally in JavaScript, and nothing you type leaves your browser.

Run the playground on your computer

With Python 3.10 or later, run these commands in your terminal.

python -m pip install medsparse-playground
medsparse-playground

The launcher opens the playground in your browser. The first model download requires internet access. View package on PyPI

Research demos. These are small models (1M–39M parameters), so their output is often wrong, repetitive or off-topic. The healthcare models are for research and engineering only: never use them for medical advice, diagnosis or treatment.

Model card ↗
Generation settings

Temperature 0 picks the most likely token every time (greedy). The repetition penalty makes already-generated tokens less likely; set it to 1 to turn it off.
